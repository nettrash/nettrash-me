Support

Applies to: md — the Markdown editor published by nettrash on Google Play (me.nettrash.md), version 1.2.
Last updated: 14 July 2026.

Need help?

Email nettrash@nettrash.me. Replies usually arrive within a few working days. Please include your Android version (Settings → About phone) and the app version (shown on md's Google Play listing under About this app).

What md is

md is the simplest Markdown editor for Android: write Markdown on one side and watch it render on the other, or flip between Edit and Preview, all in a warm typewriter look. Since 1.2 it is also a writer's tool — a whole book, kept as an ordinary folder of Markdown files, that you can compile to a single PDF or export as an EPUB. It opens, edits and saves your own files through Android's document system — nothing lives on a server, because there isn't one.

Quick start

  1. Open md. It starts on a fresh, untitled document — just start typing Markdown.
  2. Use the layout switch in the top bar to change how the editor and preview are shown (see below).
  3. Open Save from the overflow (⋮) menu. The first save on a new document asks where to put it and what to call it; after that, Save writes back to the same file. md also autosaves about a second after you stop typing.
  4. To edit an existing file, choose Open… from the overflow menu, or tap a .md / .markdown file in a file manager and pick md ("Open with md").
  5. New to md? Examples in the overflow menu opens the bundled sample documents, and Example Book… unpacks a complete sample book you can open in writer mode.

What md does

  • Opens, edits and saves .md / .markdown files (and plain text) through Android's Storage Access Framework — the document is written back to wherever you chose to keep it. Legacy encodings open correctly too: UTF-16 with a byte-order mark, and Windows-1251.
  • Renders a live preview covering headings, bold / italic / inline code / links / strikethrough, bullet / numbered / task lists (with nesting), fenced code blocks, block quotes, GitHub-style tables, thematic breaks, and images — including images your document references by a remote URL.
  • Renders math and diagrams in the preview — LaTeX math, Mermaid diagrams, Graphviz and PlantUML — drawn on your device, offline, by open-source engines bundled inside the app. Nothing is sent away to be rendered.
  • Offers a width-adaptive layout switch — Edit and Preview on a phone, plus Split (side by side, re-rendering as you type, with the two panes scrolling in step) on a tablet, unfolded foldable, large screen or landscape phone.
  • Gives writers a table of contents, a live word and character count, and private author notes that stay out of the rendered output.
  • Writer mode: open a folder as a book, manage its chapters and articles, compile the whole book into one PDF, or export it as an EPUB 3.
  • Prints the rendered document, exports it as a PDF, or shares a rendered PDF — real A4 pages, produced on-device through Android's print system. Share Source… shares the raw Markdown text through the system share sheet.

Common tasks

Create a new document

Choose New from the overflow (⋮) menu. md opens a blank, untitled document. It becomes a file on disk the first time you Save.

Open an existing file

Choose Open… from the overflow menu and pick a file in the system document picker, or open a Markdown / text file from a file manager and choose md. Files opened from a file manager are loaded read-only until you save; use Save As… to write your edits to a new file, or reopen the file through Open… to edit it in place.

Save and Save As

Save writes back to the current file. If there's nowhere writable yet (a brand-new document, or a file opened read-only), it falls through to a Save As… picker so you can choose the name and location. Once the document has a home, md autosaves it about a second after you stop typing, and again when you send the app to the background — so you rarely lose work.

Switch layout

The segmented control in the top bar switches between Edit, Preview, and — where the screen is wide enough — Split. On a phone in portrait there isn't room for two side-by-side panes, so only Edit and Preview are offered; rotate to landscape, unfold a foldable, or run md on a tablet and Split appears. In Split the two panes scroll in step, so the preview follows the line you're writing. The choice is remembered.

Write a book (writer mode)

A book in md is simply a folder you pick — no database, no import. Choose Open Book… from the overflow menu to adopt an existing folder, or New Book… to create one. Inside it, subfolders are chapters and Markdown files are articles, ordered by name. Show Book brings the navigator back; Close Book puts it away.

From the navigator you can create, rename, reorder and delete chapters and articles. Reordering is written back to the file names themselves, so the order you see in md is the order you see in any file manager, and the book stays readable without md.

Compile a book to PDF or EPUB

In the book navigator's overflow menu, Export as PDF… compiles the entire book — every chapter and article, in order — into one PDF, and Share as PDF sends that same compiled PDF through the share sheet. Export as EPUB… writes a real EPUB 3 with the same reading order, which you can open in any e-reader.

Print, export a PDF, or share

From the editor's overflow menu: Print… hands the rendered document to Android's print dialog, Export as PDF… writes a PDF to a location you pick, and Share Rendered PDF… sends one through the share sheet. All three produce real A4 pages from Android's print engine — pagination is line-aware, so no line of text is ever sliced in half at a page boundary. Share Source… sends the raw Markdown text instead.

Put \newpage (or \pagebreak) on a line of its own to force a fresh page. Printed and exported pages are always white with dark ink, whichever theme you are using on screen — the page is meant for paper, not for your display.

Math and diagrams

The preview renders LaTeX math (KaTeX), Mermaid diagrams, Graphviz (Viz.js) and PlantUML. These are open-source engines bundled inside the app and run on your device — the app downloads nothing to draw them, and they work with no network at all. They render in exported PDFs and EPUBs as well as on screen. One caveat: line-aware pagination protects lines of text, but a diagram taller than a single page can still be split across pages.

Private author notes

An HTML comment on a line of its own whose text begins with note: — for example <!-- note: check this date --> — is treated as a private note: it is kept out of the rendered preview, print, PDF and EPUB, and collected in the notes panel so you can jump between them. The condition matters: an HTML comment written inline, inside a line of text, is not a note — it stays in the text and shows up, verbatim, in the rendered page, the PDF and the printout. Put a note on its own line, or it is not private.

Frequently asked questions

Where are my files stored?

Wherever you put them. md never moves your documents to a server — there isn't one. Files live in the location you pick in the document picker (on-device storage, Downloads, Google Drive through the picker, an SD card, and so on). See the Privacy Policy for details.

How do I make md the default for a Markdown file?

When you tap a .md / .markdown or plain-text file in a file manager, Android shows an app chooser; pick md (and Always, if your launcher offers it). md opens the file handed to it; use Open… inside md if you'd rather browse.

My Markdown punctuation isn't being "corrected" — is that a bug?

No, that's intentional. md edits Markdown source, so it deliberately turns off autocorrect and smart-punctuation substitution — your ", -- and ... stay literal so the syntax isn't corrupted.

Why doesn't the preview show some advanced Markdown feature?

md's renderer covers everyday Markdown plus the common GitHub extensions (task lists, tables, strikethrough, fenced code). It is a faithful, fast preview rather than a full CommonMark engine, so a few rarely-used constructs may render as plain text. It is the same hand-written parser as the iOS and Mac versions of md, so a document renders the same on every platform. If something common renders wrong, please report it (see Contact).

Does md collect any data about me?

No. md collects no data and does no tracking — that is exactly what its Play Data safety answer says. There are no analytics, no advertising, no crash-reporting SDKs, and no servers operated by us for md to talk to, because none exist. Full details are in the Privacy Policy.

Then why does md ask for the INTERNET permission?

For exactly one thing: fetching an image that your own document references by a remote URL. If you write ![](https://example.com/pic.png), md has to ask example.com for that picture — in the preview, and also when you print, export a PDF, or export an EPUB, since the image has to appear on the page. That host then sees your device's IP address, exactly as it would if you had opened the link in a browser. It is your document that decides whether this ever happens: a document with no remote images causes no network traffic at all. Nothing else is uploaded, and nothing is sent to us.

What does md remember between launches?

Almost nothing. In writer mode it keeps a pointer to the book folder you picked — a persisted Storage Access Framework tree URI, in the app's private preferences (and, for a book created with New Book…, that folder's name) — so the book is still there next time. The Edit / Split / Preview choice survives a rotation or a fold, but not a cold start. All of it is local, none of it is personal, and none of it is transmitted anywhere. Closing the book discards the folder pointer.

Troubleshooting

"Save" keeps asking where to save

That happens when the current document has nowhere writable to write back to — a brand-new untitled document, or a file that was opened read-only (for example, handed to md from a file manager via "Open with"). Pick a location once with Save As…; from then on Save writes straight back to that file.

I can't find a file I saved earlier

md writes to the exact location you chose in the picker, not to a fixed "md folder". If you're not sure where it went, use Open… and browse the same provider (Drive, Downloads, etc.) you saved into. md does not keep a recent-files list of its own.

Print or Export as PDF shows nothing to print

The printed page is generated from the current document. If the document is empty, the output is empty too — add some content first. The PDF is produced entirely on-device through an offscreen WebView and Android's print engine; the only thing ever fetched from the network is an image your document itself references by a remote URL.

An image in my document doesn't appear

A remote image (https://…) needs a working connection to the host your document names — offline, or if that host is unreachable, it can't be drawn, on screen or in an export. Images stored beside your document load without any network. Math and diagrams are different: they are rendered by engines bundled in the app and always work offline.

A diagram is cut in half across two PDF pages

Pagination is line-aware, so no line of text is sliced at a page boundary — but a single diagram taller than one A4 page has to break somewhere. Shorten the diagram, or put \newpage on its own line just before it so it starts on a fresh page with a full page of room.

I can't find my book's chapters

A book is a plain folder: its subfolders are chapters and the .md files inside are articles, ordered by name. If a chapter looks empty, check that the Markdown files really are inside that subfolder. md rewrites file names when you reorder, so the order in the app always matches the order on disk.

Privacy & security

md collects no data about you and does not track you. It has no analytics, advertising or crash-reporting SDKs, and there is no server of ours anywhere in the picture. Its only Android permission is INTERNET, declared for the single purpose described above: fetching an image your own document references by a remote URL, in the preview and when printing or exporting. Your documents live wherever you saved them through the system picker; md keeps no copy of their contents. It does store one small local setting — in writer mode, a pointer to the book folder you picked — which is never transmitted. Full statement: Privacy Policy.

Cross-platform

md on Android is a port of the iOS / iPadOS and macOS app of the same name, and 1.2 brings the same feature set to all three: writer mode and books, book-to-PDF and EPUB export, A4 printing, math and diagrams, notes, and the table of contents. The Markdown parser is byte-faithful across all of them, so a document you write on one renders identically on the others, and a book is only a folder — copy it across and it opens. There is no account and nothing to sync — you move documents yourself, as ordinary files, through whatever storage you already use.

Open source

md is built on Google's first-party Jetpack / Compose libraries and AndroidX, with a hand-written Markdown parser and no third-party Gradle dependencies beyond AndroidX. The one exception, and it is deliberate: the preview's web view renders math and diagrams with four open-source JavaScript engines that ship inside the app — KaTeX for math, Mermaid for diagrams, Viz.js (Graphviz) and PlantUML. They are bundled, not downloaded: they run on your device, offline, and send nothing anywhere. The same four are bundled in the iOS and macOS versions.

Source code and issue tracker live at github.com/nettrash/md.Android for Android; github.com/nettrash/md (iOS / iPadOS) and github.com/nettrash/md.macOS are the Apple versions.

Please file bug reports and feature requests as GitHub issues — they are public by design so other users can see what's already known. For questions about your personal data, email nettrash@nettrash.me directly.
